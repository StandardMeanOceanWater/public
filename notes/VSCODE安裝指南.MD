# 🚀 天文開發小幫手：從零開始設定 VS Code

這份說明書會像教樂高積木一樣，帶你一步步安裝好所有需要的軟體。只要跟著做，就不會出錯喔！

---

## 第一階段：下載與安裝「地基」（必做）

請依序點擊以下連結，下載並安裝：

1.  **安裝 Python (程式的語言)**
    *   [點我下載 Python 3.12](https://www.python.org/downloads/)
    *   **⚠️ 最重要的一步**：安裝時，畫面上會有一個小格子寫著 **「Add Python to PATH」**，**一定要打勾！** 如果沒打勾，以後程式會找不到 Python。
2.  **安裝 VS Code (寫程式的家)**
    *   [點我下載 VS Code](https://code.visualstudio.com/)
    *   直接下載並安裝即可，全部按「下一步」。

---

## 第二階段：把 VS Code 裝飾成「專業天文台」

打開 VS Code 後，點擊左側最下方那個「積木圖示」（延伸模組），搜尋並安裝以下三個擴充功能：

1.  **Python** (微軟官方出的，必裝)
2.  **Pylance** (會自動幫你檢查拼字有沒有錯)
3.  **Jupyter** (讓你可以在寫程式時，直接看到圖表數據)

---

## 第三階段：打造專屬的「工具箱」（虛擬環境）

我們不希望大家的程式互相干擾，所以每做一個專案，都要開一個「獨立的工具箱」。

1.  在電腦上建立一個資料夾，例如 `MyProject`。
2.  在 VS Code 點選 `檔案` > `開啟資料夾` > 選擇 `MyProject`。
3.  按 `Ctrl + J` 打開下方的「終端機」（Terminal），輸入這行指令來建立虛擬環境：
    *   `python -m venv .venv`
4.  **重要！** 出現提示時，請點選「是」（允許 VS Code 使用這個環境）。

---

## 第四階段：安裝需要的「積木」（套件）

天文軟體需要很多特殊的「積木」（套件）。請在終端機輸入這行指令，一次裝好：
我
```bash
pip install numpy scipy pandas matplotlib astropy
```
*   `numpy` & `scipy`: 計算數字用的。
*   `pandas`: 整理表格資料用的。
*   `matplotlib`: 把數據畫成圖用的。
*   `astropy`: 天文專業用的（處理星體座標、亮度校準）。

---

## 第五階段：防毒軟體的設定（避開地雷）

**這一步是解決你之前提到的「防毒一直跳出來」的秘訣：**

1.  打開你的防毒軟體設定（如 Windows 安全性 > 病毒與威脅防護）。
2.  找到「排除項目」（Exclusions）。
3.  點擊「新增排除項目」，選擇 **「資料夾」**。
4.  把你的 `MyProject` 資料夾整個選進去。
5.  **為什麼要這樣做？** 這樣當你開發程式、編譯 `.exe` 檔時，防毒軟體就不會誤把它當作病毒殺掉了！

---

## 🌟 給學生的 3 個小貼士（像過馬路一樣安全）

1.  **每次寫程式前，先看右下角**：確定 VS Code 有寫「('.venv': venv)」，這樣你用的才是正確的工具箱。
2.  **如果有錯誤訊息**：不要怕！把它複製起來貼給老師看，錯誤代碼通常是最好的線索。
3.  **不要亂裝軟體**：只從官網下載你需要用的天文工具，避免電腦變成垃圾場。

---

### 老師的小提醒（給您的建議）：
*   **環境一致性**：您可以將上述安裝指令寫成一個 `requirements.txt` 檔案放在專案目錄中。學生只需執行 `pip install -r requirements.txt`，所有人安裝的套件版本就會完全一致，避免「我的電腦可以跑，你的卻不行」的問題。
*   **權限管理**：如先前討論，務必建立標準使用者帳戶，並將開發目錄設定好權限，這樣即使學生亂裝東西，也不會影響到系統核心。
