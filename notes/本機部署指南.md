# 變星測光管線 — 本機部署指南
**適用環境：Windows + VS Code + Python (python.org) + venv**
**最後更新：2026-03-09**

---

## 前置確認：Python 是否安裝正確

打開 **命令提示字元（cmd）**，輸入：

```cmd
python --version
python -m pip --version
```

**預期輸出：**
```
Python 3.10.x  （或 3.11 / 3.12，均可）
pip 23.x.x
```

**如果看到錯誤或 `python` 找不到：**
1. 開始功能表搜尋「新增或移除程式」→ 找到 Python → 解除安裝
2. 前往 https://www.python.org/downloads/ 重新下載
3. 安裝時 **務必勾選「Add Python to PATH」**（預設沒勾，這是最常見的問題）
4. 安裝完成後重新開啟 cmd 確認

---

## 第一步：在 VS Code 開啟專案資料夾

1. 開啟 VS Code
2. 左上角 **File → Open Folder**
3. 選擇 `D:\VarStar\pipeline`
4. VS Code 左側 Explorer 應該看到你的 `.py` 和 `.ipynb` 檔案

---

## 第二步：建立 Python 虛擬環境（venv）

在 VS Code 上方功能列選 **Terminal → New Terminal**，會在下方開啟終端機。

確認終端機路徑是 `D:\VarStar\pipeline`，然後依序輸入：

```cmd
python -m venv .venv
```

執行完成後，你會看到 `pipeline/` 資料夾裡多了一個 `.venv` 資料夾，這就是你的獨立 Python 環境。

**啟動虛擬環境：**

```cmd
.venv\Scripts\activate
```

成功後終端機最左邊會出現 `(.venv)` 字樣：

```
(.venv) D:\VarStar\pipeline>
```

> **每次開啟新的終端機都要重新執行這行啟動指令。**
> VS Code 重新開啟後也要再啟動一次。

---

## 第三步：告訴 VS Code 使用這個虛擬環境

1. 按 `Ctrl + Shift + P` 開啟命令面板
2. 輸入 `Python: Select Interpreter`，按 Enter
3. 清單裡選擇有 `.venv` 字樣的那個（通常顯示為 `Python 3.x.x ('.venv': venv)`）

選完之後，VS Code 右下角狀態列應該顯示你選的 Python 路徑。

---

## 第四步：安裝所有套件

虛擬環境啟動後（確認有 `(.venv)`），執行：

```cmd
pip install "numpy>=1.24" "pandas>=2.0" "scipy>=1.10" "matplotlib>=3.7"
pip install "astropy>=5.3" "photutils>=1.9"
pip install "rawpy>=0.18" "exifread>=3.0"
pip install "tqdm>=4.65" "pyyaml>=6.0" "requests>=2.28" "packaging>=23.0"
pip install jupyter ipykernel
```

全部完成後確認：

```cmd
pip list
```

應該看到上面所有套件都出現在清單中。

---

## 第五步：讓 Jupyter 認識這個虛擬環境

```cmd
python -m ipykernel install --user --name varstar --display-name "VarStar Pipeline"
```

這樣在 Jupyter Notebook 裡就可以選擇「VarStar Pipeline」這個 kernel。

---

## 第六步：確認 VS Code 的 Jupyter 擴充功能已安裝

1. 左側點擊 Extensions 圖示（方塊拼圖圖示）或按 `Ctrl + Shift + X`
2. 搜尋框輸入 `Jupyter`
3. 找到 **Jupyter**（Microsoft 出品），確認已安裝
4. 同樣搜尋 **Python**（Microsoft 出品），確認已安裝

---

## 第七步：執行 00_setup.ipynb 驗證環境

1. 在 VS Code 左側 Explorer 點擊 `00_setup.ipynb`
2. 右上角 kernel 選擇器選擇 **VarStar Pipeline**
3. 按 `Ctrl + Shift + P` → `Jupyter: Run All Cells`，或逐格按 `Shift + Enter`

**Cell 1** 應該輸出：
```
執行環境：本機 / JupyterLab
Python 版本：3.x.x
設定檔路徑：D:\VarStar\pipeline\observation_config.yaml
✅ 環境偵測完成
```

**Cell 2 + 3** 安裝並驗證套件版本。

**Cell 5** 輸出目錄狀態報告，確認新建或已存在，並列出任何孤立目錄。

**Cell 6** 驗證 ASTAP：
- 如果 `astap_cli.exe` 的路徑和 yaml 裡的 `astrometry.astap.executable` 不符，會報錯
- 請打開 `observation_config.yaml` 確認路徑正確，例如：
  ```yaml
  astap:
    executable: "C:/Program Files/astap/astap_cli.exe"
    db_path: "C:/Program Files/astap/h18"
  ```

---

## 第八步：執行管線（步驟 1–3）

環境驗證完成後，在終端機（確認 `(.venv)` 啟動）執行：

```cmd
python run_pipeline.py --config observation_config.yaml
```

**只跑某個步驟：**
```cmd
python run_pipeline.py --config observation_config.yaml --steps calibration
python run_pipeline.py --config observation_config.yaml --steps plate_solve
python run_pipeline.py --config observation_config.yaml --steps debayer
```

**從某步驟開始跑到底：**
```cmd
python run_pipeline.py --config observation_config.yaml --from-step plate_solve
```

**列出所有步驟：**
```cmd
python run_pipeline.py --list-steps
```

## 常見問題

### `(.venv)` 消失了，套件找不到

虛擬環境沒有啟動。重新執行：
```cmd
.venv\Scripts\activate
```

### VS Code 終端機預設是 PowerShell，`activate` 失敗

PowerShell 執行 venv 啟動腳本需要權限，改用 cmd：
1. 終端機右上角下拉箭頭 → **Command Prompt**
2. 或在 VS Code 設定（`Ctrl + ,`）搜尋 `terminal.integrated.defaultProfile.windows`，改為 `Command Prompt`

### `rawpy` 安裝失敗

rawpy 需要 Visual C++ 執行庫。前往 https://aka.ms/vs/17/release/vc_redist.x64.exe 下載安裝後重試。

### ASTAP 找不到星表

確認 `db_path` 指向的目錄裡有 `.290` 或 `.dat` 檔案。
Cell 6 會自動計算目錄內的星表檔案數量，若顯示 0 個，代表路徑錯誤或星表未解壓縮。

### `ModuleNotFoundError: No module named 'Calibration'`

表示執行 `run_pipeline.py` 時，Python 找不到同目錄的模組。
確認終端機的當前路徑是 `D:\VarStar\pipeline`：
```cmd
cd D:\VarStar\pipeline
python run_pipeline.py --config observation_config.yaml
```
