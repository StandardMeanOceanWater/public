## 如何使用這份文件

1. 進入 claude.ai → 選取你的變星專案 → Project Settings → Instructions
2. 把上方「貼入 Claude Project Instructions 的內容」區塊的全文複製貼上
3. 把 `PIPELINE_STATUS.md` 上傳到 Project Knowledge（不是對話附件）
4. 之後每次新對話，Claude 會自動讀取 Project Knowledge，不需要手動上傳

## 每次新對話的開場語（建議）

```
請讀 PIPELINE_STATUS.md 後繼續。今天要做的是：[說明本次工作]。
相關檔案已附上：[列出附上的檔案]。
```

## 更新 PIPELINE_STATUS.md 的時機

每次有以下任何一項發生，就更新並重新上傳到 Project Knowledge：

- 有新的學理決策被確認
- 有模組狀態改變（完成、發現 bug、待修）
- 有新的已知限制被發現
- 有待實作清單的項目完成或新增

## 命名規則

- `DESIGN_DECISIONS_v{N}.md`：學理規格書，有重大結構修訂時加版號
- `PIPELINE_STATUS.md`：狀態快照，永遠只有一份，直接覆蓋更新
- 所有 `.py` 和 `.ipynb`：不加版號
- 請直接輸出完整程式碼，盡量使用Arifact
- 生成文件除非有另外指定，請用MD優先
